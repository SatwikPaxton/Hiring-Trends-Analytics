**Hiring Trends & Talent Demand Analytics**

This project analyzes job postings from regions like Penang and Singapore to uncover hiring trends, in-demand skills, and emerging industry patterns. It uses Python, Pandas, SQL-like analysis, and visualization tools.

**Features**

Extract most demanded skills across thousands of job descriptions

Identify most frequently posted job titles

Clean & preprocess job posting datasets

Generate charts showing hiring patterns

Designed for students, analysts, and recruiters

** Tech Stack**

Python (Pandas, NumPy, Matplotlib, Seaborn)

Jupyter / Script-based analysis

CSV dataset processing
**
📁 Dataset Description**

job_postings_sample.csv includes:

Column	Description
job_title	Title of the position
company	Hiring company name
location	City / country
description	Full job description text
date_posted	Posting date
